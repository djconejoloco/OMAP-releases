# OMAP

Editor de mapas de orientación y trazado de recorridos para Windows.

Descarga el instalador `OMAP-Setup-….exe` de la [última versión](https://github.com/djconejoloco/OMAP-releases/releases/latest).

Windows puede avisar de que el programa no está firmado: pulsa **Más información › Ejecutar de todas formas**.

Una vez instalado, OMAP avisa cuando hay una versión nueva.
